## Mes projets (en BUT)
🃏 Jeu de cartes roguelike (Java) — inspiré d'Inscryption
Un jeu de cartes en Java s'inspirant de l'univers d'Inscryption, avec une architecture orientée objet : gestion des cartes via un pattern factory, utilisation d'Optional<T> pour éviter les nulls, séparation stricte entre logique de jeu et affichage, et une suite de tests JUnit couvrant les mécaniques principales (combat, pioche, tours).

🌀 Gestion de missions Stargate (C# WinForms)
Application de gestion de missions au thème Stargate, développée en C# avec WinForms, en équipe. Intègre une base SQLite, l'authentification sécurisée (BCrypt), la génération de rapports PDF (iTextSharp) avec une identité visuelle sci-fi, et une interface soignée (starfield animé, filtrage dynamique).
